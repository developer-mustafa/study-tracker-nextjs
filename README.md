# FocusStudy (ফোকাসস্টাডি) — Bengali Study Productivity SaaS

> **"মনোযোগ দিয়ে পড়ো, লক্ষ্য পূরণ করো"**

FocusStudy হলো একটি পূর্ণাঙ্গ বাংলা স্টাডি প্রোডাক্টিভিটি অ্যাপ্লিকেশন। এটি শিক্ষার্থীদের পড়ার রুটিন সাজানো, টাস্ক ট্র্যাকিং, পোমোডোরো ফোকাস সেশন, স্টাডি স্ট্রিক ও গভীর অ্যানালিটিক্স প্রদানের মাধ্যমে পড়াশোনার শৃঙ্খলা রক্ষা করতে সাহায্য করে।

---

## বৈশিষ্ট্যসমূহ (Key Features)

1. **ব্যক্তিগত ড্যাশবোর্ড (Personalized Dashboard)**:
   - বাংলায় অভিবাদন ও আজকের পড়ার লক্ষ্য অগ্রগতি
   - ৬টি মূল পরিসংখ্যান কার্ড (আজকের পড়ার সময়, মোট পড়ার সময়, সম্পন্ন কাজ, ফোকাস সেশন, স্টাডি স্ট্রিক, লক্ষ্য পূরণ হার)
   - ইন্টারঅ্যাক্টিভ বার চার্ট (শেষ ৭ দিন ও ৩০ দিনের অ্যানালিটিক্স)
   - বিষয়ভিত্তিক প্রগ্রেস বার এবং রিয়েল-টাইম অ্যাক্টিভিটি টাইমলাইন

2. **পোমোডোরো ফোকাস টাইমার (Pomodoro Focus Timer)**:
   - মোডসমূহ: ফোকাস (২৫ মিনিট), ছোট বিরতি (৫ মিনিট), বড় বিরতি (১৫ মিনিট), কাস্টম টাইমার
   - অ্যাবসোলিউট ডেডলাইন ভিত্তিক সঠিকতা (ট্যাব সুইচ, ডিভাইস স্লিপ বা পেজ রিফ্রেশেও সময় সঠিক থাকে)
   - সাউন্ড অ্যালার্ট ও সেশন সমাপ্তিতে কনফেটি সেলিব্রেশন
   - বিষয় ও নির্দিষ্ট টাস্ক ট্যাগিং

3. **কাজ ব্যবস্থাপনা (Task Management)**:
   - সম্পূর্ণ CRUD (তৈরি, সম্পাদনা, সম্পন্ন, মুছে ফেলা)
   - অগ্রাধিকার লেভেল: কম, মাঝারি, উচ্চ, জরুরি
   - ফিল্টারিং: সব কাজ, আজকের কাজ, আসন্ন, অসম্পন্ন, সম্পন্ন, সময় উত্তীর্ণ
   - সার্চ এবং ডেডলাইন ট্র্যাকিং

4. **স্টাডি প্ল্যান ও সিলেবাস (Study Plans)**:
   - সিলেবাস টপিক চেকলিস্ট ও স্বয়ংক্রিয় শতাংশ হিসাব
   - বিষয় নির্ধারণ ও টার্গেট ডেট
   - প্ল্যান ডুপ্লিকেট ও সম্পাদনা সুবিধা

5. **অগ্রগতি ও রিপোর্ট (Analytics & Streaks)**:
   - বাংলাদেশ টাইমজোন (Asia/Dhaka) ভিত্তিক ধারাবাহিক স্ট্রিক ক্যালকুলেশন
   - বিষয়ভিত্তিক পড়ার সময় তুলনা ও চার্ট

6. **নোটস ও রিভিশন (Notes)**:
   - বিষয় ও ট্যাগভিত্তিক ফিল্টারিং, সার্চ এবং ফেভারিট পিনিং

7. **স্টাডি ক্যালেন্ডার (Study Calendar)**:
   - মাসিক ক্যালেন্ডার গ্রিড, প্রতিদিনের অধ্যয়ন মোট সময় ও ডেডলাইন মার্কার

8. **অর্জনসমূহ (Achievements)**:
   - প্রথম সেশন, ৫টি সেশন, ১০ ঘণ্টা পড়াশোনা, ৫/৭/৩০ দিনের স্ট্রিক, ২৫টি কাজ সমাপ্তির মতো ৮টি অনন্য ব্যাজ

9. **মূল্যতালিকা ও সাবস্ক্রিপশন (Monetization)**:
   - ফ্রি, প্রো (৳১৯৯/মাস) এবং প্রিমিয়াম (৳৩৯৯/মাস) টিয়ার

10. **অ্যাডমিন প্যানেল (Admin Panel)**:
    - মোট শিক্ষার্থী মেট্রিক্স, সাবস্ক্রিপশন ওভারভিউ এবং সিকিউরিটি অডিট লগ

## টেকনোলজি স্ট্যাক (Technology Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Canvas Confetti
- **Backend / Persistence**: Firebase Authentication, Cloud Firestore, Offline-first reactive client store
- **Security**: Hardened Firestore Security Rules (`firestore.rules`) adhering to zero-trust architecture
- **Testing**: Node.js Native Test Runner (`node:test`, `tsx`)

## সেটআপ ও রান করার নিয়ম (Installation & Run)

```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# ডেভেলপমেন্ট সার্ভার চালু (Port 3000)
npm run dev

# ইউনিট টেস্ট রান
npx tsx --test src/lib/utils/timer.test.ts src/lib/utils/streak.test.ts

# প্রোডাকশন বিল্ড
npm run build
```

## ফায়ারবেজ কনফিগারেশন (Firebase Setup)

প্রজেক্টটি স্বয়ংক্রিয়ভাবে একটি অফলাইন-ফার্স্ট রিঅ্যাক্টিভ স্টোরেজ মোডে চালু থাকে। ক্লাউড সিঙ্ক চালু করতে:
1. Firebase Console-এ একটি প্রজেক্ট তৈরি করুন।
2. `.env` ফাইলে আপনার ওয়েব ক্রেডেনশিয়াল যুক্ত করুন:
   ```env
   VITE_FIREBASE_API_KEY="YOUR_KEY"
   VITE_FIREBASE_PROJECT_ID="YOUR_PROJECT_ID"
   ```
3. `firestore.rules` এবং `firestore.indexes.json` ফায়ারবেজে ডেপ্লয় করুন।
